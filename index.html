วิธีติดตั้งครั้งแรก

ทำครั้งเดียวต่อหนึ่งไฟล์ Google Sheet

  1. เปิดไฟล์ Google Sheet ปลายทาง → เมนู Extensions → Apps Script
  2. ลบโค้ดเดิมใน Code.gs ทิ้ง แล้ววางโค้ดด้านล่างนี้ลงไป
  3. แก้ SECRET เป็นรหัสลับของคุณเอง แล้วบันทึก
  4. Deploy → New deployment → type = Web app
    Execute as = Me · Who has access = Anyone
  5. กด Authorize access อนุญาตสิทธิ์ · ถ้าเจอหน้าเตือน ให้กด Advanced → Go to … (unsafe)
  6. คัดลอก Web app URL ที่ลงท้าย /exec มากรอกช่องด้านซ้าย พร้อมรหัสลับเดียวกัน

แก้โค้ดครั้งใด ต้อง Deploy → Manage deployments → Version = New version ไม่งั้น URL เดิมจะยังรันโค้ดชุดเก่า
